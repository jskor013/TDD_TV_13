## 주의 사항

- 남은 리스크:
  - Cursor의 `.cursor/agent` 파일 형식은 프로젝트 로컬 Agent 지침으로 작성했다. 실제 Cursor 기능과 연동되는 방식은 사용 중인 Cursor 버전에 따라 다를 수 있다.
  - 현재 작업 중 생성된 최종 응답은 커밋 이후 사용자에게 별도 전달되므로, 프롬프트 기록에는 커밋 직전까지의 대화와 수행 내용이 포함된다.
- 후속 작업:
  - 필요하면 `.cursor/rules` 또는 공식 Cursor Rules 형식으로 동일한 루틴을 추가할 수 있다.

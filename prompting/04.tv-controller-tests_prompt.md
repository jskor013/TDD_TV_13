- **Stateful Mock**: `FAV_NEXT` 연속 입력 시 `setCH` 후 `getCurrentCH`가 갱신되도록 `ON_CALL` 연동
- **POL-01/02**: 빈 버퍼 `OK`, 빈 선호 `FAV_NEXT` → `setCH` 0회

### 최초 빌드 중 컴파일 오류 (수정 완료)

`ReturnRef(currentChannel_)` 사용 시 `getCurrentCH()` 반환 타입이 `std::string`(값)이라 컴파일 실패.

```
error: static assertion failed: use Return instead of ReturnRef to return a value
```

→ `expectStatefulCurrentChannel()` 헬퍼로 `[this] { return currentChannel_; }` 람다 사용으로 수정.

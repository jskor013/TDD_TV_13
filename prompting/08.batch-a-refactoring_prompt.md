### A1 — 순환 탐색 단일화 + `std::optional` (#1, #4)

| 항목 | 내용 |
|------|------|
| 작업 | `CyclicDirection`, `cyclicNeighbor()` 추가 |
| 치환 | `channelUpWithSearch`, `channelDownWithSearch`, `handleFavNext`의 `-1` 센티널 제거 |
| 검증 (전체) | `cmake --build .; ctest` |
| 검증 (집중) | `ctest -R "REQ_UD_S|REQ_FAV_N|REQ_FAV_C|README_fav|README_ch_up_down"` |

**핵심 변경** (`include/TVController.h`):

- `static std::optional<int> cyclicNeighbor(int current, const std::vector<int>& channels, CyclicDirection dir)`
- Forward: 첫 `ch > current`, 없으면 `front()`
- Backward: 역순 첫 `ch < current`, 없으면 `back()`

## 1) Expected 출력 파일 생성·보관 전략

| 항목 | 내용 |
|------|------|
| **저장 위치** | `test/golden/<TestSuite>/<TestName>.golden.txt` |
| **형식** | TextTest 스타일 transcript — `> KEY` 입력 줄 + `std::cout` 로그 |
| **버전 관리** | `*.golden.txt`는 Git에 커밋 (기준 스냅샷) |
| **실패 시** | `*.received.txt`를 같은 폴더에 생성 (`.gitignore` 제외) |

예시 (`README_digit_1_ok.golden.txt`):

```
> 1
> OK
현재 설정하는 채널 : 1
```

**Golden 갱신 방법** (둘 중 하나):

```powershell
# 방법 A: CMake 옵션
cmake -S . -B build -DUPDATE_GOLDEN_MASTER=ON
cmake --build build
.\build\TextTestGoldenTest.exe
cmake -S . -B build -DUPDATE_GOLDEN_MASTER=OFF   # 일반 모드로 복귀

# 방법 B: 스크립트
.\scripts\update_golden.ps1

# 방법 C: 환경 변수 (빌드 옵션 없이)
$env:GOLDEN_UPDATE="1"; .\build\TextTestGoldenTest.exe
```

## 2) Google Test 파일 비교 구현

- **`test/support/GoldenMaster.hpp`** — 읽기/쓰기, CRLF 정규화, `assertMatchesGolden()`
- **`test/support/CoutCapture.hpp`** — `std::cout` 캡처
- **`test/TextTestGoldenTest.cpp`** — `TextTestFixture`가 키 입력 transcript + 로그를 수집 후 golden과 비교

핵심 흐름:

```cpp
void press(std::initializer_list<remoteKey> keys) {
    for (remoteKey key : keys) {
        transcript_ << "> " << to_string(key) << '\n';
        CoutCapture capture;
        controller_.pushButton(key);
        transcript_ << capture.str();
    }
}
void assertGolden() {
    golden::assertMatchesGolden(suite, test, transcript_.str());
}
```

기존 `TVControllerTest`(Mock 기반)와 **역할 분리**: Mock은 `setCH` 계약 검증, Golden은 **로그 출력 회귀** 검증.

## 3) CMake / ctest 통합

`CMakeLists.txt`에 추가된 내용:

- `TextTestGoldenTest` 실행 파일
- `GOLDEN_EXPECTED_DIR` → 소스 트리 `test/golden` 고정
- `UPDATE_GOLDEN_MASTER` 옵션
- `gtest_discover_tests(TextTestGoldenTest)` → ctest에 12개 케이스 자동 등록
- `update-golden` 커스텀 타겟

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure          # Golden 포함 93 tests
ctest --test-dir build -R TextTestFixture           # Golden만 12 tests
```
